title: Review configuration changes before release
type: operations
applies_when: A release depends on configuration assembled by one person

---

**Lesson** - Require a peer review before configuration changes reach production.

**Why** - A second reader catches assumptions and transcription mistakes that the author no longer sees.

**Watch out** - Keep the review focused on risky changes so it does not become a ceremonial approval step.
